# Katch — Telegram Mini App

Рабочий продукт для кліперов и брендов внутри Telegram:
- украинский по умолчанию + английский;
- регистрация через Telegram (первый вход = регистрация, без форм и паролей);
- первый экран: «Я кліпер» / «Я бренд»;
- кліпер: главная с калькулятором заработка → оффери с полным ТЗ → «Взяти» → подпись `#katch #k7f2q` → кабинет, куда он вставляет все ссылки на клипы → статусы → вывод на USDT (TON) или карту; «Скасувати оффер» — все невыплаченное по офферу сгорает;
- бренд: бриф в чат, калькулятор просмотров за бюджет, пример отчета;
- «Назад» с любого экрана до первого;
- вкладка «Навчання»: уроки-аккордеоном для кліперов (12) и брендов (6), с примерами и мини-тестами, прогресс запоминается на устройстве;
- светлая и темная тема: по умолчанию темная, переключатель в шапке и в Профиле.

Без интеграций с TikTok/Instagram/YouTube: просмотры ты вписываешь руками в базе.

```
index.html                      — вся апка (один файл, без сборки)
config.js                       — единственное, что надо поменять: адрес сервера, ник менеджера, ставки калькуляторов
learn.js                        — тексты уроков «Навчання» (UA и EN), правятся без кода
supabase/schema.sql             — база: таблицы, автоподсчет выплат, вьюхи для тебя
supabase/seed_example.sql       — тестовый оффер (удалить перед запуском)
supabase/functions/api/index.ts — сервер: проверка входа Telegram и все действия апки
```

Пока в `config.js` пустой `API_URL`, апка работает в демо-режиме на выдуманных данных.

## Запуск (≈ 1 час)

### 1. Бот — 5 минут
1. В Telegram открой **@BotFather** → `/newbot`.
2. Имя: `Katch`, юзернейм, например `katch_ua_bot`.
3. Сохрани **токен** (вида `123456:ABC…`). Никому не показывай и не клади в код.

### 2. База Supabase — 10 минут
1. [supabase.com](https://supabase.com) → New project, регион Frankfurt.
2. **SQL Editor** → New query → вставь весь `supabase/schema.sql` → **Run**.
3. Для теста запусти так же `supabase/seed_example.sql`.
4. Запомни **Project Ref** из адреса проекта: `https://<REF>.supabase.co`.

### 3. Сервер — 10 минут
1. **Edge Functions** → Deploy a new function → **Via Editor**, имя функции **`api`**.
2. Вставь весь `supabase/functions/api/index.ts` → Deploy.
3. В настройках функции **выключи «Verify JWT»**. Иначе будет ошибка 401: вход проверяем через Telegram.
4. **Edge Functions → Secrets**: `BOT_TOKEN` = токен из шага 1. По желанию `MIN_PAYOUT` = минимальный вывод в $ (по умолчанию 10).
5. Адрес сервера: `https://<REF>.supabase.co/functions/v1/api`

### 4. Сайт апки на GitHub Pages — 10 минут
1. В `config.js` впиши `API_URL: 'https://<REF>.supabase.co/functions/v1/api'` и ник менеджера в `MANAGER`.
2. Файлы лежат в репозитории `katch-app`.
3. Репозиторий → **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты сайт будет по адресу `https://danilorlov.github.io/katch-app/`.

### 5. Подключить к боту — 5 минут
1. @BotFather → `/mybots` → бот → **Bot Settings → Menu Button** → вставь адрес сайта, текст: `Відкрити Katch`.
2. Там же `/newapp` → прямая ссылка вида `t.me/katch_ua_bot/app` для каналов и чатов кліперов.

### 6. Проверка — 15 минут
1. На телефоне открой бота → кнопка меню → апка откроется, ты уже зарегистрирован.
2. «Я кліпер» → тестовый оффер → ТЗ → «Взяти» → скопируй подпись.
3. «Відкрити кабінет» → вставь пару ссылок TikTok, каждую с новой строки → «Надіслати на перевірку».
4. Supabase → **Table Editor → clips**: впиши `views` = 30000 и `status` = `approved`. В апке клип станет «Зараховано · холд до …».
5. Проверь на iPhone и Android.
6. Удали тестовый оффер: `delete from offers where brand = 'ТЕСТ';`

> Вне Telegram (просто в браузере) апка с настоящим `API_URL` пишет «Відкрий апку через бота в Telegram». Так и должно быть: без Telegram нет входа.

## Ежедневная работа — Supabase Table Editor

| Что | Где | Что делаешь |
|---|---|---|
| Новый оффер после брифа | `offers` → Insert row | бренд, название (uk/en), **ТЗ в `brief_uk`/`brief_en`**, ставка кліперу за 1000 (`rate_per_1k`), бюджет на выплаты, макс. за клип, требования в `rules_uk` (каждое с новой строки), ссылка на исходники |
| Проверка клипов | вьюха `review_queue` | `day` ≥ 7 → открываешь ролик, проверяешь код `#k…` в подписи |
| Засчитать клип | `clips` | `views` + `status = approved` → выплата и холд 7 дней считаются сами |
| Отклонить клип | `clips` | `status = rejected`, причину в `reject_reason` — кліпер ее увидит |
| Выплаты | вьюха `payouts_todo` | отправил деньги → в `payouts` ставишь `status = sent` и `sent_at` |
| Отчет бренду | вьюха `campaign_report` | клипы, просмотры, потрачено |
| Пауза оффера | `offers` | `status = paused` или `done` |

Выплата: `views / 1000 × rate_per_1k`, не больше `max_per_clip`. Через 7 дней после «approved» деньги доступны к выводу.

**Отмена оффера кліпером:** все его клипы по этому офферу, которые еще не ушли на выплату (на проверке, засчитанные, в холде), становятся `rejected` с причиной «Оффер скасовано», сумма обнуляется. Уже запрошенное на вывод и выплаченное остается. Скасованный оффер можно взять снова, будет новый код.

## Что важно знать
- **Токен бота** живет только в Secrets Supabase. В `config.js` и в репозитории его быть не должно: репозиторий публичный.
- **Номера карт** хранятся в базе. Доступ к Supabase — только ты и Руслан, включи 2FA.
- **Бюджет оффера не блокируется сам.** Когда `spent` в `campaign_report` подходит к бюджету, ставь `paused`.
- **Уведомлений пока нет.** Следующий шаг: бот пишет кліперу, когда клип засчитан или отклонен.
